# ARC Raiders 網頁版（單人搜打撤）

受《ARC Raiders》玩法啟發的粉絲自製網頁遊戲，純 HTML5 Canvas + JavaScript，無需建置，手機與電腦皆可遊玩。

## 玩法
- **斯佩蘭薩基地**：配裝（兩把武器、護盾、背包、安全口袋）、倉庫、商人、工坊升級、任務、技能樹。
- **地表遠征**（約 7 分鐘）：三張地圖（大壩戰場、埋葬之城、太空港），搜刮箱子與 ARC 殘骸，對抗 8 種 ARC（黃蜂、大黃蜂、跳蚤、火球、跳躍者、哨兵砲塔、堡壘、女王）與 AI 掠手。
- **撤離**：呼叫撤離電梯並守住 25 秒，進入電梯撤離。死亡會失去所有未放進安全口袋的物品；破產可領免費基礎裝備。
- 武器升級影響換彈速度與穩定度，不加傷害；命中中心可爆頭 2.5 倍。

## 操作
- 電腦：WASD 移動、滑鼠瞄準射擊、Shift 衝刺、E 互動、R 換彈、Q 換槍、H 治療、C 護盾、G 手雷、Tab 背包、M 地圖、Esc 暫停
- 手機：左半邊虛擬搖桿移動、右半邊搖桿瞄準並自動開火、右下按鈕操作（建議橫向）

## 本機執行
```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

## 部署到 Vercel
在 Vercel 匯入此儲存庫，Framework Preset 選「Other」，不需要 Build Command，直接 Deploy。之後每次推送到 `main` 會自動重新部署。

本作與 Embark Studios 無關。
